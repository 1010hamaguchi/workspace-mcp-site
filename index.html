workspace-mcp(個人利用)

このページは、浜口慶一郎が自分自身の Google アカウントのデータを扱うために登録した OAuth アプリ「workspace-mcp」の説明ページです。アプリは一般に配布しておらず、利用者は登録者本人のみです。

アプリの概要

  • 実体は公開されている MCP サーバ workspace-mcp で、登録者本人の端末上で動作します。
  • 本人が許可した Google アカウントの Gmail、Google カレンダー、Google Tasks を、本人が操作する AI アシスタントから読み書きするために使います。

プライバシーポリシー

  • 取得するデータ: 本人が許可した Google アカウントのメール、カレンダー、タスクの内容。
  • 利用目的: 本人による閲覧、整理、作成の補助。
  • 取り扱い: データは本人の端末から Google の API を直接呼び出して取得し、本人の端末以外のサーバーに送信・保存しません。第三者への提供、広告目的の利用、販売は行いません。
  • 保存するもの: 本人の端末内に OAuth の認証トークンのみを保存します。本人はいつでも Google アカウントの設定からアクセス権を取り消せます。
  • Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。

利用規約

このアプリは登録者本人の個人利用のみを目的としており、第三者への提供や保証は行いません。
